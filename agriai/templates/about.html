ABOUT A.G.R.I.

Advanced Ground Reporting Intelligence

A.G.R.I. is an AI-powered agricultural soil intelligence system designed to simplify soil understanding and improve farming decisions using smart technology and intelligent analysis.

🌱 What is AGRI?

A.G.R.I. combines soil sensor data, climate intelligence, GPS-based environmental information, and artificial intelligence to generate detailed agricultural analysis reports. The system helps understand soil conditions intelligently without depending entirely on traditional laboratory testing.

📈 What AGRI Analyzes

💧 Moisture
🧪 Soil pH
⚡ Conductivity / TDS
📍 GPS Location
🌦 Climate Intelligence
🌡 Temperature & Humidity

🤖 Features of AGRI

✓ Soil Classification
✓ Crop Recommendation
✓ Fertility Analysis
✓ Irrigation Advice
✓ Pest Risk Prediction
✓ Soil Improvement Suggestions
✓ Sustainable Farming Guidance
✓ Smart Agricultural Reports

⚙ Technologies Used

ESP32 Django Gemini AI Open Meteo OpenStreetMap HTML CSS JavaScript

📄 How It Works

1 → Collect Data
2 → Climate Analysis
3 → AI Processing
4 → Smart Report Generation

🎯 Project Goal

The primary objective of A.G.R.I. is to make agricultural soil intelligence more accessible, affordable, and data-driven for farmers, students, researchers, and agricultural professionals. The system aims to support smarter farming decisions and sustainable crop management using practical AI-powered analysis.
